# Web Application Penetration Testing Report – DVWA

## 📌 Project Overview
This project is a capstone cybersecurity internship task focused on performing a web application penetration test on DVWA (Damn Vulnerable Web Application) in a controlled lab environment.

The objective is to identify vulnerabilities, exploit them ethically, and recommend mitigation strategies while simulating an incident response.

## 🎯 Objectives
- Perform reconnaissance and scanning
- Identify OWASP Top 10 vulnerabilities
- Exploit vulnerabilities in controlled environment
- Suggest mitigation strategies
- Simulate incident response process

## 🛠 Tools Used
- Kali Linux
- DVWA (Damn Vulnerable Web App)
- Nmap
- Burp Suite
- Hydra
- Browser Dev Tools

## 🔍 Vulnerabilities Tested
- SQL Injection
- Cross Site Scripting (XSS)
- File Inclusion (LFI)
- Brute Force Attack

## 🚨 Incident Response
A simulated security incident was created and analyzed using logs. Steps included:
- Detection
- Containment
- Eradication
- Recovery
- Lessons learned

## 📂 Repository Contents
- Methodology documentation
- Commands used during testing
- Screenshots of findings
- Final penetration testing report

## ⚠️ Disclaimer
This project was performed in a legal and controlled lab environment for educational purposes only.
